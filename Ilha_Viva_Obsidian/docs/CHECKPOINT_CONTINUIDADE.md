Não extrapolar resultado do ensaio para fazendas reais.
Fundamento consultado em 27/11/2026: USDA NRCS National Agronomy Manual https://www.nrcs.usda.gov/sites/default/files/2022-10/National-Agronomy-Manual.pdf ; Penn State Inoculation of Forage and Grain Legumes https://extension.psu.edu/inoculation-of-forage-and-grain-legumes ; University of Georgia White Clover Establishment and Management Guide https://fieldreport.caes.uga.edu/publications/B1251/white-clover-establishment-and-management-guide/ ; University of Missouri https://extension.missouri.edu/publications/wq277 . Rizóbios compatíveis recebem energia da planta, fixam N atmosférico para o hospedeiro, atividade depende das condições e é inibida por N disponível. UGA informa 100–150 lb N/acre/ano para estande vigoroso; não se trata de taxa universal. Teto sintético 100 kg N/ha/ano, fração hospedeira fixa 25%, custo 8 kg C/kg N, C:N alvo 18/25 e inibição mineral 0,002 kg/m² são hipóteses não calibradas. Fixação limitada por luz, temperatura, água, N mineral, C da fração hospedeira e déficit N do estoque vegetal agregado. Entrada N atmosférico vai ao estoque vegetal; custo C sai como respiração de fixação explícita, não energia medida em joules. Não modela população real de rizóbios, nodulação, crescimento independente das espécies, fungos ou micorrizas. Custo de C e entrada N contabilizados nos balanços acumulados.
Resultados após 3 anos: controle C 1327,499 / N 147,973 kg; somente deposição C 1421,509 / N 156,970 kg; somente proteção/liberação C 1418,770 / N 148,956 kg; somente repartição inicial C 1975,729 / N 150,301 kg; três fatores C 2087,953 / N 159,967 kg; três fatores + fixação C 2088,060 / N 159,982 kg. Estoques iniciais C 2990,206 e N 174,368 kg em todos. Fixou 0,016396 kg N com custo 0,131166 kg C, tudo no primeiro ano; anos 2/3 não acrescentaram fixação.
