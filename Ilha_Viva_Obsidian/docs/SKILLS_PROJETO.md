# Biblioteca de skills do projeto

## Regra vigente
A biblioteca é memória operacional versionada, complementar ao GDD e ao checkpoint. A cada missão, ler as skills pertinentes antes de trabalhar; ao concluir, transformar aprendizados comprovados em procedimentos reutilizáveis. Não duplicar documentação nem chamar hipótese de solução validada. Registrar gatilho, procedimento, evidência, limitações, falha evitada e commit. Atualizar skill quando uma regressão revelar nova regra. Preservar histórico Git. Nenhuma skill autoriza trocar direção artística ou migrar engine sem aprovação.

As seis skills são procedimentos iniciais, não prova de execução ou certificação. A pasta segue formato SKILL.md com frontmatter name/description; leitura explícita via repositório é obrigatória quando a ferramenta não oferece descoberta automática. Não afirmar instalação global ou treinamento permanente do modelo. Criar novas skills somente quando houver necessidade repetível; próximos candidatos: terreno procedural orgânico, agricultura e pecuária, narrativa contextual, economia e performance mobile.
